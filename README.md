# CodeSense 2.0 — Live Code Mutation Engine (Кейс 3 · Tomorrow School)

**CodeSense** — полнофункциональная веб-система для проведения интерактивных P2P-аудитов в **Tomorrow School** по кейсу **Live Code Mutation Engine — ИИ-аудитор понимания кода**.

Система принимает проект студента (через загрузку файлов или импорт GitHub-репозитория на **Go**, **Rust** или **JavaScript**), анализирует структуру программы (функции, ветвления, циклы), автоматически вносит и верифицирует тестами **ровно 3 осмысленные логические мутации** и запускает 10-минутную P2P-защиту с контролем честности без LLM-помощников, синхронизацией экрана аудитора в реальном времени и сохранением результатов в **базу данных SQLite**.

---

## Реализация по каждому пункту Кейса 3

1. **Приём кода студента (Файлы + GitHub-импорт + языки Go, Rust, JS):**
   - Загрузка исходных файлов (`.go`, `.rs`, `.js`) и `tests.json` через Drag-and-Drop.
   - Прямой импорт GitHub-репозитория по URL (`POST /api/github/import`) + встроенные проекты для демонстрации на **Go (`order.go`)**, **Rust (`scorer.rs`)** и **JavaScript (`order.js`)**.
2. **Анализ структуры программы (`dist/engine.js`):**
   - Лексический и структурный анализатор определяет функции (`func`, `fn`, `function`, `=>`) с их именами и номерами строк, условия (`if`, `switch`, `match`), циклы (`for`, `while`, `do`, `loop`) и потенциальные точки логических мутаций, игнорируя строки и комментарии.
3. **Автоматическая генерация 3 проверенных мутаций:**
   - Кандидатные изменения операторов сравнения и границ (`>=` ↔ `>`, `<=` ↔ `<`), логических условий (`&&` ↔ `||`, `===` ↔ `!==`) и арифметики/возврата (`+` ↔ `-`) поодиночке прогоняются через изолированный тестовый раннер (Web Worker).
   - Выбираются ровно **3 мутации на разных строках**, каждая из которых гарантированно ломает хотя бы один тест при сохранении запускаемости программы.
4. **Интерактивная среда для студента:**
   - Встроенный редактор кода, переключение файлов проекта, запуск тестов с наглядным сравнением ожидаемого и полученного результата (`Expected` vs `Actual`) и блок фиксации найденных причин ошибок.
5. **10-минутная P2P-защита без LLM-помощников:**
   - Обратный отсчёт на `10:00` с автоматическим завершением и блокировкой редактора по истечении времени.
   - Встроенный модуль **Anti-LLM Guard**: автоматическое отслеживание потери фокуса/переключения вкладок (`visibilitychange`) и крупных вставок из буфера обмена (`paste`) с мгновенной отправкой сигналов аудитору.
6. **Интерфейс P2P-аудитора в реальном времени:**
   - Синхронизация через **Server-Sent Events (`GET /api/audits/:id/stream`)**, REST API и `BroadcastChannel` (можно подключиться по короткому коду комнаты вида `TS-101`).
   - Скрытая от студента **Карта 3 мутаций**, живой просмотр кода студента, журнал запусков тестов и **интерактивный чек-лист аудитора** для подтверждения понимания каждой из 3 ошибок.
7. **Итоговый отчёт, Авторизация и База Данных (Учителя, Аудиторы, Студенты):**
   - Серверная БД на встроенном движке **SQLite (`node:sqlite` -> `data/codesense.db`)** с таблицами `users`, `sessions` и `audits`.
   - Роли: **Студент** (`student`), **P2P-Аудитор** (`auditor`) и **Преподаватель / Ментор** (`teacher`).
   - Панель «База: Учителя и Студенты» со статистикой школы, списком всех участников, архивом P2P-защит и возможностью преподавателя выставить финальный вердикт (`Зачтено` / `На доработку` / `Подозрение на ИИ`).

## Быстрый запуск локально

Требуется Node.js 18+ (рекомендуется Node.js 22+ для встроенного `node:sqlite`, внешние npm-пакеты не требуются):

```bash
node server.cjs
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).

### Готовые демо-аккаунты в БД (доступны также в 1 клик из боковой панели):
- **Студент:** логин `student` / пароль `student123` (Алихан Садыков)
- **P2P-Аудитор:** логин `auditor` / пароль `auditor123` (Тимур Бектуров)
- **Преподаватель / Ментор:** логин `teacher` / пароль `teacher123` (Арман Есенов)

## Автотесты

```bash
node test.cjs
node integration-test.cjs
```

Проверяются: лексический разбор, генерация ровно 3 мутаций на JS, Go и Rust, выполнение в Worker, таймаут бесконечного цикла (2 сек), восстановление кода, формирование отчёта `6/6` и `3/3`, работа БД SQLite и авторизации.

## Деплой в облако (Render / Railway / Docker)

В проект уже добавлены конфигурационные файлы для деплоя в 1 клик:
- **`render.yaml`** — для деплоя на [Render.com](https://render.com) (New -> Blueprint -> подключить GitHub-репозиторий `https://github.com/timelesseternal/projectapp`).
- **`railway.json`** — для деплоя на [Railway.app](https://railway.app) (Deploy from GitHub repo).
- **`Dockerfile`** — для любого контейнерного хостинга (Fly.io, Google Cloud Run, VPS):
  ```bash
  docker build -t codesense .
  docker run -p 4173:4173 codesense
  ```
